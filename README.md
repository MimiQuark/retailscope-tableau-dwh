# RetailScope: Retail Data Warehouse and Tableau Decision Dashboard

Retail sales data warehouse project built with Python, SQLite/MySQL-compatible SQL, star-schema modeling, KPI views, and Tableau 2026.2.

- 113,306 sales fact rows
- 14 KPIs and 4 multi-chart Tableau dashboards
- Tableau professional workbook, PDF and HTML preview
- 9 data-quality checks and 7 automated tests passed

Run: `.\01_sql_dwh_tableau_dashboard\run.ps1`
